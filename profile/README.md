# Juiceframe 🧃

**Make AI sprites feel like a real game.**

AI sprite generators get you frames. Juiceframe makes them *playable*:

- 🦶 **Feet stay on the floor.** No skating, no hopping.
- 🔁 **Loops that don't pop.** The cleanest cycle in your clip, found and closed.
- ⚔️ **Hits that land.** Impact frames marked, with hit-stop, flash and knockback you can toggle.
- 🧾 **A quality receipt for every clip.** Measured, not promised.

Works with output from any sprite generator. Built for game developers *and* their AI coding agents (UI, CLI, API and MCP over the same commands).
